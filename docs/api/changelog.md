# Журнал изменений API

## 1.0.0 — 2026-11-23

- Зафиксирован первый OpenAPI 3.0.3 контракт текущих REST операций.
- Описаны игровой процесс, игроки, аутентификация, альбом и административные операции.
- Зафиксирован единый формат ошибок RFC 9457 (`type`, `title`, `status`, `detail`).
- Ошибки Bean Validation возвращаются с кодом 422, некорректный JSON — 400.
